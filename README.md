Bu proje, Bilişim Teknolojileri Web Geliştirme dersi kapsamında, sıfırdan geliştirilmiş tam donanımlı bir **Blog ve İçerik Yönetim Sistemi (CMS)**'dir. Ziyaretçiler için bir haber akışı, yöneticiler için ise güvenli bir yönetim paneli barındırır.

## 🌟 Proje Özellikleri

- **🔐 Oturum Yönetimi (Session):** Sadece yetkili yöneticilerin giriş yapabildiği güvenli Admin Paneli.
- **📝 Dinamik İçerik Yönetimi:** Veritabanı (MSSQL) destekli makale ekleme ve listeleme (CRUD işlemleri).
- **📬 İletişim Formu ve Moderasyon:** Ziyaretçilerin mesaj gönderebildiği ve yöneticilerin bu mesajları panelden okuyabildiği sistem.
- **🎨 Modern Arayüz:** Bootstrap 5 kullanılarak tasarlanmış, mobil uyumlu (Responsive) kullanıcı arayüzü.
- **🛡️ Model Validation:** C# Data Annotations ile güçlendirilmiş form güvenliği ve hata yönetimi.

## 🛠️ Kullanılan Teknolojiler
* **Backend:** C#, ASP.NET Core MVC (v8.0)
* **Veritabanı & ORM:** Microsoft SQL Server, Entity Framework Core
* **Frontend:** HTML5, CSS3, Bootstrap 5
